# EduFaros — Education Growth Systems

The official EduFaros website, built with Next.js, React, TypeScript and React Three Fiber.

## Experience direction

- Obsidian-black foundation with electric teal and electric blue accents.
- Responsive, editorial homepage architecture.
- Interactive 3D growth-engine visual in the hero.
- Motion-aware section reveals and a reduced-motion fallback.
- SEO metadata, sitemap and robots configuration.
- No fabricated client numbers, testimonials or case-study results.

## Local development

Install dependencies with npm install, then start the local development server with npm run dev. Use npm run build to create the production build and npm run typecheck to check TypeScript types.

## Before launch

Confirm the production domain, replace any remaining structural copy with approved company copy, connect the real contact or booking destination, add verified case studies and social links, review the privacy and terms pages, and test the site on actual mobile devices.
