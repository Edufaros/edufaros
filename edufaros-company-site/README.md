# EduFaros Company Website

This is a separate Next.js application scaffolded inside the EduFaros repository.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Project structure

- `app/page.tsx` — homepage
- `app/layout.tsx` — root layout and metadata
- `app/globals.css` — global styles

This is an initial workspace shell, not the approved final website design.
